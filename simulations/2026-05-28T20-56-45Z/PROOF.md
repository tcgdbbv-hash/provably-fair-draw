## What this proves

1. **No reroll.** The `commitment_hash` was determined at step 2 from a
   secret seed the operator generated and bound themselves to. Any
   attempt to switch seeds after the fact would change the
   `commitment_hash` and break this chain.
2. **No prediction.** The `public_seed` came from a drand round published
   79 seconds *after* the commit. The operator demonstrably could not
   have known the randomness when choosing the server seed.
3. **No bias.** The selection algorithm rejection-samples a uniform
   integer in `[0, |remaining|)` per pick, so distribution is exact, not
   approximate.
4. **No tampering.** Anyone can re-clone this repo, run the `verify`
   command above, and arrive at the same 3 winners. If a different
   `wallets.txt`, `server_seed`, or `public_seed` had been used, the
   winners would change deterministically — making any swap detectable.
